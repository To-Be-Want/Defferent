# 星轨智学 · 独立 Agent 版

基于现有学习产品代码建立的独立项目。原项目 `../xingguizhixue` 未被修改；本项目不包含其账号、课件或数据库。经用户授权，本机 .env 复用现有模型接口配置，不纳入版本管理。继承代码继续遵循根目录 LICENSE。

## 启动

Python 3.11 或 3.12。在本目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-agent.txt
Copy-Item .env.example .env
# 在 .env 填写模型 API_KEY、API_BASE_URL、MODEL_NAME 和自行设置的注册邀请码。
.\.venv\Scripts\python.exe cloud_app.py -p 7790
```

打开 http://127.0.0.1:7790/cosight/ ，注册新账号，在学习设置中允许在线模型，然后上传资料。也可运行 `start_backend.ps1`。本地端口 7790，与原项目 7788 分开。本机注册邀请码见不纳入版本管理的 `本地访问说明.md`。生产部署需配置 HTTPS、`COSIGHT_COOKIE_SECURE=true`，不要直接公开本地演示配置。

数据默认保存在本项目 `data/users/<用户ID>/`。如设置 `COSIGHT_DATA_DIR`，务必指向新目录，不能指向原项目。当前按单服务进程设计；跨进程锁与任务队列需要在多 worker 部署前补充。

## 当前架构

浏览器 → FastAPI / WebSocket → `study_gateway.answer` → `learning_agent.runtime`。

LangGraph 节点：`think → tools → think`；需修改计划/考试日期时转入 `approval`，使用 SQLite checkpoint 和 interrupt 持久化暂停。每个账号有独立状态库。模型传输位于 `learning_agent/model.py`，可接支持工具调用的 OpenAI 兼容接口。不是训练新模型。

`learning_agent/tools.py` 是工具注册和参数校验入口，复用资料解析、排期、小测、错题和学习记录。新主入口不调用旧快慢分流器或 CoSight DAG 调度。保留的旧引擎文件仅供迁移参考，不作为新项目的运行入口。

## 产品约束

- 以上传课件为主，尽量还原原文符号、推导顺序、算法及代码思路。补充方法应标注，不能把模型生成的内容说成资料原文。
- 检索当前最多扫描12份文件，每份前120000字符，选8段原文。采用关键词检索，尚未加入向量检索；文件多、扫描质量差或跨页内容可能漏检，需要实测后优化。
- 小测正常记录成绩、掌握度和薄弱状态，补测失败也不自动改计划。
- 生成/调整计划先做确定性排期预览，展示任务日期、耗时变化、延误和考前缺口。只有用户回复 `确认执行 <本次编号>` 才保存预览中的同一批任务。泛泛的“好的”不能批准。
- 方案待确认时发送其他请求会取消旧方案，再处理新请求。同一天内方案有效；学习状态或计划发生变化后必须重新预览。
- 考试日期修改同样需要确认。主页主动保存考试设置不会自动重排计划。
- 所有账号数据边界由服务端计算；模型不能传入用户身份、任意路径或执行 shell。对话没有手工伪造小测成绩的工具。

## 验证

```powershell
.\.venv\Scripts\python.exe tools/verify_agent.py
```

新 Agent 测试使用真实 LangGraph 和 SQLite、临时账号、模拟模型，不产生模型费用。继承的旧测试中依赖快慢分流、自动重排或旧浏览器任务图的断言需要按新设计迁移，不能作为新引擎验收标准。

真实模型的工具选择准确率、数学教学正确性、课件还原度、延迟和费用仍需要用真实课程进行验收。OCR、自动出题和模型阅卷保留原有能力及其限制；框架迁移不能保证答案正确。

复制来源及复制时的文件哈希见 `SOURCE_SNAPSHOT.json`，不含原项目密钥与运行数据。

资料分类纠正：已解析资料也可修改科目或课件/真题用途。改科目时直接调整本文件知识块、真题及统计归属，保留解析结果和成绩，无需重新解析；改课件/真题用途时才归档旧解析并要求重新解析。现有计划不会自动调整。解析中暂不可修改。

聊天响应：初始上下文仅使用已缓存文本或小文本文件，不自动对大PDF/图片执行OCR；需要原文时显式调用读取工具。文本缓存按账号和文件签名隔离，文件变化自动失效。页面显示阶段进度和每10秒等待提示。

知识点位置索引：SQL 保存资料版本、文本片段及知识点与片段的关联，包含缓存字符起止位置、段落和可用的 PDF 页码。教学优先按知识点直接读取原文；生成学习计划的初始上下文只读数据库中的知识点、依赖与学习状态。旧缓存可运行 `tools/backfill_source_index.py` 补建索引，不调用模型或 OCR。章节及关键词关联属于自动定位候选，需要核对原文；旧缓存缺少页码时不猜测页码，目前不提供页面坐标框。缓存上限为 200 万字符，超出部分标记为截断。

响应提示：显示正在定位知识点、读取课件、组织讲解或计算排期等实际阶段，配合动态圆点与已用时间；不展示模型内部思维过程。
