# 团队手动确认上线

有仓库 Write（写入）或以上权限的协作者，可以在 GitHub 执行：

1. 把通过检查的代码合并到 `main`。
2. 打开仓库 **Actions → 手动更新星轨智学服务器 → Run workflow**。
3. 分支选择 `main`，勾选“确认把 main 最新代码部署到服务器”。
4. 点击 **Run workflow**，查看运行结果。绿色代表成功；失败时展开日志查看原因。

只想验证连接时，勾选“仅检查部署连接”，不会更新代码。普通 push 不会触发上线。

运行过程会拉取 main、备份源码和学习数据、更新并检查健康状态。正在运行完整引擎任务时会拒绝更新，请稍后重试。更新操作排队执行，避免多人同时部署。

用于 Actions 的 SSH 密钥只能调用固定的检查或更新入口，不允许终端、端口转发或任意命令。不要把个人登录包或服务器私钥发给其他人。
