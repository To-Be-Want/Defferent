# 2026-10-28 学习流程修复

## 资料库主动解析

“我的资料”中每份文件可选择“课件 / 真题”后点击“解析”。需先选择科目并允许在线模型；无需考试日期。课件建立知识块和标明估计性质的题型依据，真题提取题目并参与考点统计、真题练习排期；能匹配到知识块的题型也供后续小测使用。

解析在后台完成，显示待解析、解析中、已解析或失败及重试入口。重新打开资料库可查看状态，服务重启后中断的任务可重试。同一账号一次解析一份；已解析文件再次解析需要确认。

同科多文件累积保存，同文件重新解析替换本文件来源的数据，保留同名同章节知识块的掌握度、历史成绩和现有计划。解析失败保留上次成功结果。已解析文件不能直接改科目或用途，以免混入另一门课。解析不会创建或重排学习计划，未填考试日期的课程等待设置日期后再排期。模型识别、知识拆分和题型匹配仍可能有误；课件估计不代表真实考试频率。

以下为此前的学习流程说明。

本次基于服务器 `/home/ubuntu/Co-Sight` 的源码快照，保留队友的语义分流、识别和部署依赖。

- 短确认承接上一轮小测或计划提议。即时小测不依赖已有知识块，题数和选项校验后才落库。
- 答题弹窗支持选择、多选、判断、文字作答及照片识别。照片转写需用户核对；提交前不向浏览器提供参考答案。
- 答题草稿按账号和试卷保存在本机，重新打开可继续。提交后可主动将题目加入错题本。
- 简单资料总结直接整理学习内容，内容识别用于待分类资料；用户手动分类保持优先。
- 不把模型内部 reasoning 字段作为答案，不交付达到长度上限的半份输出。
- 最终回答与任务执行详情分开；回答可放大阅读和复制。
- 完整任务记录按用户保存，步骤模型复核提供依据而非虚构百分比。节点颜色表示复核状态，外圈表示执行状态。
- 运行时心跳、整体时限和失败状态避免无限停留在“进行中”；重启后的陈旧记录显示中断提示。
- 自然语言事项先识别、预填，再由用户确认保存；支持多项选择、日期确认与已有时间段冲突提醒，不自动重排考试。

限制：模型复核不保证答案正确；手写和公式识别可能有误，必须核对转写。时间冲突检查仅覆盖已有明确时间段的事项。原始历史报告不会被自动改写，旧任务缺失的可信度不能追溯伪造。

本地测试使用临时账号、模拟模型和浏览器，不上传用户学习资料到真实模型。
